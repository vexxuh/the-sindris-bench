Fonts bundled here are unmodified variable-font files from Google Fonts
(https://github.com/google/fonts), each under the SIL Open Font License 1.1
(see the matching `*-OFL.txt` next to each font). OFL permits bundling and
redistribution, including in commercial software, without royalty.

- `SpaceGrotesk.ttf` — ofl/spacegrotesk, headings and tracked-uppercase labels.
- `Inter.ttf` — ofl/inter, body/UI text.
- `JetBrainsMono.ttf` — ofl/jetbrainsmono, diff/JSON content and meta chrome.

These are variable fonts; we load them at their default (Regular) instance
only. Weight contrast is done via size, not multiple static weight files.
